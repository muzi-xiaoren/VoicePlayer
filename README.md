# VoicePlayer

[English](./README_EN.md) | 中文

轻量级 Windows 声卡音效热键工具（类 Soundpad）。按下全局快捷键，把音效混进麦克风，
一起打游戏 / 开黑的人就能听到你的音效——同时**不影响你正常说话**。

## 功能一览

- **卡片式界面**：音效以网格卡片排布，带搜索框、正在播放高亮；设置独立成一页，主界面只留音效
- **外观可调**：主题跟随系统 / 深色 / 浅色；背景色可自定义（卡片、输入框、描边的明暗会跟着一起变）；
  可设背景图片并调节图片不透明度；整窗不透明度 0–100%，压低后能看见后面的桌面 / 游戏
- **音量档位**：右键任意音量滑块弹出预设档位一键选择，档位可在设置里自定义
- **多音效混播**：多个音效可同时播放，互不干扰
- **热键绑定**：每个音效绑定全局快捷键，另有「停止所有音效」快捷键
- **主键盘 / 小键盘独立绑定**：数字键 1 和小键盘 1 可绑成不同音效，互不影响
- **一键锁定**：锁定后快捷键不再触发，避免误触
- **不拦截按键**：绑定的键仍能正常打字，不会吞键
- **重复按键行为三选一**：从头重播 / 叠加再播 / 一按播再按停
- **系统音频捕获**：把电脑正在播放的声音（音乐、视频等）混入虚拟麦克风
- **应用音频路由**：把指定应用（网易云、浏览器等）的音频单独送进虚拟麦克风
- **耳机监听**：让自己也能听到音效
- **多语言**：中文 / English，默认跟随系统语言
- **开机自启**：可设置开机自动启动
- **窗口位置记忆**：下次打开自动恢复上次的位置和大小

## 工作原理

游戏 / Discord 是从「麦克风」采集声音的。VoicePlayer 自己做混音：

```
真麦克风 ──┐
          ├─→ VoicePlayer 混音 ──→ CABLE Input ──→ 游戏麦克风 = CABLE Output
音效文件 ──┘                        (VB-CABLE 虚拟声卡)
```

因为混音在程序内部完成，所以**不需要 VoiceMeeter**，只需要一根「哑管道」虚拟声卡，
用免费的 [VB-CABLE](https://vb-audio.com/Cable/) 即可。

## 使用步骤

1. 安装 [VB-CABLE](https://vb-audio.com/Cable/) 并重启电脑。
2. 打开 VoicePlayer，切到**「设置」**页，**输出设备**选 `CABLE Input (VB-Audio Virtual Cable)`。
3. 在游戏 / Discord 里，把**麦克风**设成 `CABLE Output (VB-Audio Virtual Cable)`。
4. 回到**「音效」**页，点 📂 打开文件夹，把 mp3 / wav / ogg / flac 拖进去，会自动出现在网格里。
5. 在音效卡片上点「＋ 设快捷键」，按下想要的组合键即可。
6.（可选）想自己也能听到音效，在「设置」页把「监听设备」设成你的耳机。

> 注意：游戏麦克风设成了 CABLE Output，所以 **VoicePlayer 需要一直开着**转发真麦；
> 关掉程序后游戏里会没声音。可勾选「开机自启动」。

## 系统音频捕获（两种方式）

想把电脑正在播放的声音（音乐、视频等）也送到游戏麦克风里？有两种方式：

### 方式一：系统音频捕获（全部系统声音）

适合把**所有系统声音**一次性混入虚拟麦克风。

1. 打开 VoicePlayer，切到「设置」页找到「系统音频捕获」分组
2. 勾选 **「捕获系统音频到麦克风」**
3. 用「捕获音量」滑块调整混入的音量大小
4. 现在电脑播放的任何声音（音乐、视频、游戏音效等）都会混入虚拟麦克风

> 注意：这种方式会捕获**所有**系统声音，包括系统提示音。如果只想送某个应用的声音，用下面的方式二。

### 方式二：应用音频路由（指定某个应用）

适合只想把**某一个应用**的声音送进虚拟麦克风，其他应用不受影响。

1. 打开 VoicePlayer，切到「设置」页找到「应用音频路由」分组
2. 点 **「打开应用音量设置」**，Windows 会弹出「声音设置 → 应用音量」页面
3. 在列表里找到你想送声音的应用（比如网易云、Chrome 浏览器等）
4. 把它的**输出设备**改成 `CABLE Input (VB-Audio Virtual Cable)`
5. 现在只有这个应用的声音会送到虚拟麦克风，其他应用照常从扬声器播放

> 比如你在网易云把输出设备改成 CABLE Input，队友就能听到你放的歌；同时浏览器看视频的声音仍然从你的扬声器正常播放。

## 数据目录

配置和音频放在 `%APPDATA%\VoicePlayer\`：

```
%APPDATA%\VoicePlayer\
├─ config.json        # 全局配置
└─ profiles\
   └─ 默认\
      ├─ xxx.mp3
      └─ _bindings.json   # 快捷键绑定
```

## 从源码构建

需要 Rust 工具链（`rustup`）。仅支持 Windows 运行（音频用 WASAPI）。

```bash
cargo run            # 调试运行
cargo build --release
```

发布：推一个 `v` 开头的 tag（如 `v0.0.3`），GitHub Actions 会自动构建
绿色版 zip + 安装包并发到 Release。
